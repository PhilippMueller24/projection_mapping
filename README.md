# Projection Mapping

A TouchDesigner-based projection mapping project for creating and controlling immersive visual experiences.

## Project Structure

- **projection_mapping.toe** - Main TouchDesigner project file
- **aztec_layers/** - Contains layer files and assets for Aztec-themed visuals
- **movies/** - Video content and media files (ignored in git)
- **Backup/** - Project backup versions (ignored in git)

## Getting Started

1. Open `projection_mapping.toe` in TouchDesigner
2. Configure your projection setup and display settings
3. Load media from the `movies/` directory or add custom content
4. Use the `aztec_layers/` assets for visual composition

## Requirements

- TouchDesigner 2021.18000 or later
- Compatible projection hardware
- Video content in supported formats

## Notes

- Backup files are excluded from version control to keep the repository clean
- Media files should be managed locally to reduce repository size
